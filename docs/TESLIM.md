## Teslim formunda istenenler

- Oyun adı ve kısa açıklama
- Platform: **Web**
- Oynanabilir bağlantı: GitHub Pages adresi
- En az 1 dakikalık oynanış videosunun bağlantısı. YouTube'da "Liste dışı" yüklenebilir; hesapsız açıldığını kontrol et. Kayıt için Windows'ta Win+Alt+R (Xbox Game Bar) ya da OBS.
- Public repo bağlantısı
- **Tam commit kimliği** (40 karakter, `git rev-parse HEAD`). Oyun menüsündeki "sürüm" yazısıyla aynı commit olmalı.
- Kurulum, çalıştırma ve kontrol talimatları (README'den)
- Hazır kaynak beyanı (README'den)
- Yapay zekâ beyanı (README'den)
- Kuralları kabul onayı

## Son kontrol

- [ ] Oyun bağlantısı gizli sekmede, hesapsız açılıyor ve baştan sona oynanıyor
- [ ] Menüdeki sürüm, teslim edilen commit'le aynı
- [ ] Repo public
- [ ] README güncel: oyun açıklaması, kontroller, çalıştırma, beyanlar, tema öncesi son commit
- [ ] Oyundaki Emeği Geçenler ekranı güncel (takım üyelerinin adları!)
- [ ] Video en az 1 dakika ve hesapsız açılıyor
- [ ] Teslim makbuzu alındı; kayıt no, sürüm, saat ve bağlantılar kontrol edildi
- [ ] 5 dakikalık sunum provası yapıldı
- [ ] Son teslimden sonra `main`'e push yapılmayacak (yayın otomatik değişir)
